# 📚 Học Web cùng KhanhPC

Tại đây, bạn sẽ được cung cấp các **file bài học từ cơ bản đến nâng cao** về **HTML**, giúp bạn bắt đầu hành trình trở thành lập trình viên web chuyên nghiệp.

## 📁 Nội dung khóa học

- ✅ Bài học HTML cơ bản
- ✅ Thực hành HTML nâng cao
- ✅ Dự án nhỏ áp dụng thực tế
- ✅ Mẹo và kiến thức mở rộng

## 🚀 Bắt đầu ngay

> Clone repository để bắt đầu học:

```bash
git clone https://github.com/HoangQuocKhanh0504/hocwebkhanhpc.git

---

💡 **Cách sử dụng:**  
1. Dán nội dung trên vào file `README.md` trong root thư mục GitHub của bạn.
